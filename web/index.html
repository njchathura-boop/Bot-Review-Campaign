07 / LOCAL ONBOARDING

Run Detectra on your machine

A developer path from a fresh clone to a live review, streaming campaign, and observable result. Training is optional for normal local serving.

  1. 01Clone + installPython 3.11 or 3.12, Git, DVC, and Docker Desktop
  2. 02Restore dataConfigure the team DVC remote and pull, or rebuild from raw inputs
  3. 03Check artifactsReview and campaign model folders must exist before API startup
  4. 04Start the stackAPI, Kafka, Spark, scorer, MLflow, Prometheus, Grafana, and Kibana
  5. 05Replay a campaignThe UI publishes reviews and shows the scored campaign path
  6. 06Verify + observeRead live service probes, dashboards, logs, lineage, and tests

FAST PATH

Start an already-trained workspace

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev,mlops,streaming,ui]"
# after configuring the shared DVC remote
python -m dvc pull

docker compose --profile stream --profile observability up -d `
  api kafka kafka-init spark-master spark-worker spark-stream `
  campaign-scorer mlflow prometheus grafana elasticsearch kibana
